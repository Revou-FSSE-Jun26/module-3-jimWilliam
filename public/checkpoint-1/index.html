About

Backend first, frontend second. In Module 2 I built the RevoTech Flask API — users, categories, products, orders and order items on PostgreSQL, with JWT auth and a Swagger spec. Module 3 puts a real interface on top of it.

My approach is to get the data model right before styling anything. Every product on this page comes from the same catalogue the API serves, so the types line up from the database through to the React components in the later checkpoints.

Currently

Shipping the RevoTech frontend on Next.js and Tailwind, deployed to Vercel and covered by a Playwright end-to-end suite.
